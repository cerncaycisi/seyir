# i18n convention

- `app/src/main/res/values/` is the **Turkish default**; `values-en/` is English. Matching resource files must contain the same translatable keys.
- Use `stringResource(R.string.key)` in Compose (and `context.getString` elsewhere). No hard-coded user-visible text in new code.
- Key naming: `<screen>_<purpose>`, e.g. `onb_accept`, `about_title`, `crash_share`. Shared words: `common_*`. Use a screen prefix per owner to avoid merge conflicts.
- Placeholders: positional (`%1$s`, `%2$d`) so translations can reorder.
- `app_name` is a single non-translatable resource ("Seyir"); never write the name in other strings, pass it as an argument.
- Apostrophes in XML must be escaped (`\'`).
- Resources are grouped into `strings.xml`, `ui_strings.xml`, `player_strings.xml`, `record_strings.xml`, `data_strings.xml`, and `app_strings.xml`.
- To add a language: create `values-<code>/`, translate every key, and add the language to the settings picker.
- Home, Live, Playlists, Series, Player, recordings, phone pairing, and service errors now use resources. Provider titles, programme descriptions, language names, and technical format names remain unchanged.
- `DisplayPreferences` applies the selected locale and clock format to Compose immediately. Background services use `SettingsStore.localizedContext` from `AppLanguage.kt`.
- Keep App Bundle language splitting disabled so switching languages also works offline.
